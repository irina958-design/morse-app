# Support

Report reproducible problems through GitHub Issues. English and Russian are welcome.

Include your Morse version, Windows version, installer or portable, exact steps, expected behavior and actual behavior. Add a screenshot if it helps.

Settings → Support can prepare a diagnostic report. Read it before sharing. Full logs are optional and may contain information you should remove. Never attach your entire user-data folder, game files, tokens or passwords.

For mod-specific content problems, include the original GameBanana page so we can distinguish a manager issue from an issue with the mod itself.
